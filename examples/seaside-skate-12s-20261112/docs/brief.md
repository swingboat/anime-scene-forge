# 《海风里的暑假》

12秒 / 1280×720 / 24fps / 288帧 / 16:9。无对白、无字幕、无配乐。风格handpainted-film；用户参考宫崎骏电影的日系手绘质感，原创人物与场景。

一位短发女孩，米黄色短袖上衣、蓝色短裤、白色运动鞋，单一原木色滑板、银色桥架、四枚浅色轮子。双脚横站板面并始终贴合，膝盖轻屈，手臂自然平衡；轻柔海风吹动短发、衣角和白/粉/淡紫花朵。只做平稳滑行，无蹬地、跳跃或特技。

空间轴线：女孩沿同一海岸山坡柏油路从画面左向右行进，陆地在镜头侧，大海在道路远侧；收尾道路向右前方远去。午后阳光来自画面左上，投影向右。水粉花海前景、道路中景、大海与云天空远景。

0–4秒远景建立地形，女孩滑入；4–8秒侧面完整跟拍；8–12秒斜后方拉开，海天占比增加。每镜96帧，连续源帧、原生24fps、1倍速，无静图轮播或循环补时。先内部完成2–4秒滑行短测并检查，然后扩展。

声音：轻柔立体声海风、远处低缓海浪，以及随镜头距离变化的滑板轮子在柏油路上的滚动声。代理不能直接听觉验收，保留可调独立音轨。
