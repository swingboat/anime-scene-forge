# 《海风里的暑假》制作记录

2026-11-12，handpainted-film。状态：已制作；完成内部逐帧、1倍速播放与技术检查，采用当前候选并保留以下细节限制。用户艺术验收未确认。

## 独立工程与来源

本工程由本仓库初始化器创建为examples/seaside-skate-12s-20261112，12秒、1280×720、24fps、288帧，三个96帧镜头。全部运行素材、依赖、模型、缓存、日志和输出留在当前目录。

内置imagegen制作三幅原创机位原画；侧面原画固定单一女孩与滑板身份，另两幅以它为参考。实际提示词在docs/prompts/*-image-effective.txt；图像工具未暴露具体模型版本。原图及其哈希在docs/generation/artwork.json。宿主默认在generated_images保留原件，无法配置该工具内部输出目录；已复制入本片，运行不读取宿主原件。ffmpeg仅作全画幅1024×576输入归一化。

本机Apple Silicon / MLX路线：Python3.13.9，MLX0.32.4、mlx-lm0.32.2，LTX-2.3 q4、Gemma3-12b q4；固定源码提交747b30ef10e92a011e85b2aa0f6c4ee86ced5218。版本与模型修订在docs/mlx-profile.json、docs/generation/environment.json和python-freeze.txt。float32、11GiB MLX限额、cache0、提示词缓存、顺序文本编码加载和逐块DiT读取；一次只运行一个视频GPU任务。

已有本机模型通过APFS clonefile复制为本片独立inode文件，无软/硬链接，没有下载新模型。导入工具只在准备时读取指定来源，生成脚本只读取本片.cache/models。源码按固定提交重新克隆，.venv和node_modules在本片重新安装，未共享其他视频的虚拟环境。模型导入记录在outputs/checks/environment-materialization.json。

## 关键滑行短测

先生成scene-02-v1：整幅场景连续I2V，原生1024×576、24fps、97帧，采用源0–95帧（4.000秒）作为侧面跟拍。源候选、生成日志和有效视频提示词及输入/输出哈希均保留。推理流水线575.44秒（原后端日志Time570.6秒；包装器墙钟576.32秒），MLX峰值10.903GiB。

实际查看全96帧完整画面、接触放大与脸部图，分别见scene-02/full-01..08、contact-01..08、face-01..08。原生1倍速、不静音播放从0到4秒结束，媒体error=null；浏览器实际播放时间记录在scene-02-review.json。未把脚本成功或技术分数当作艺术通过。

观察：米黄/蓝/白服装、短发脸型、单一木色板保持一致；双脚站板、近侧两轮贴路，未见核心离板离地或板身解体；膝盖、低位双臂、头发和衣角有连续变化，前景视差方向一致，海平线和地理大结构稳定。

限制：侧面末段约3.7–4.0秒前景白花短暂遮挡前部板轮；细花叶/海面笔触轻微波动；望海动作幅度很轻，以沿路向前为主。原样保留并记录，没有裁切隐藏。内部采用该方案后才启动另外两个连续视频镜头；不将本次短测扩展为复杂运动或其他宿主的保证。

## 声音

无对白、字幕和配乐。make_ambience.py以固定seed61112作原创程序环境声设计（滤波噪声、缓慢海浪起伏、随镜头距离与横向位置变化的柏油滚轮声），不是野外录音。四条独立48kHz立体声PCM16 WAV包含风、远浪、滚轮及混音；音频构成、哈希和峰值在docs/generation/audio.json，精确时长检查在outputs/checks/audio-pcm-check.json。候选模型自带音轨不采用。代理无法直接试听，声音自然度和最终听感未获人耳验收。
