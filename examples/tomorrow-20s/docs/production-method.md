制作日期：2026-11-11（Asia/Shanghai）。状态：**已制作；内部视觉/技术检查通过；用户尚未验收。**

## 成片与工程

- `outputs/final.mp4`：H.264/AAC，1280×720，24fps，480帧；视频、音频与容器时长均20.000秒，文件8,578,100字节。
- 五镜各96帧，剪点为第96/192/288/384帧；每条原生1024×576、24fps的97帧连续A2V源采用0—95帧，**1倍速**，无冻结、循环或变速补时。第2镜先检查完整画面及手部，再按中近景意图裁取源x192/y0/832×468；其余镜头完整画幅，统一Lanczos缩放交付。
- Remotion预览：`npm run dev -- --port 3310`，修改`production.json`热更新；画面合成在`src/Root.tsx`。工程自身的依赖、模型、素材、缓存、日志和输出都在本片目录。
- 工程ZIP由`npm run package`生成，包含源码、锁文件、素材、原始候选、采用片段、制作/检查记录和成片；可重装的node_modules、虚拟环境、模型和缓存不放进ZIP，仍保存在当前完整工程目录。打包命令输出CRC及包内影片哈希校验，结果在`outputs/checks/package.json`。

## 声音先行与表演

先确定角色声线描述、情绪和正常语速，再生成五句WAV。仅做恒定增益与48kHz双声道PCM16转换，**没有加速或截词**。原速对白补真实头尾静音为97帧driver，不含配乐；采用画面和最终对白使用同一driver样本/哈希及源偏移。候选自带音轨不进入成片，成片只混合采用WAV。

| 镜头 | 台词 | 原速长度 | 成片音频起点 |
|---|---|---:|---:|
| scene-01 | 今天的演讲……又搞砸了。 | 3.44秒 | 0.250秒 |
| scene-02 | 紧张很正常。明天继续练。 | 2.48秒 | 4.375秒 |
| scene-03 | 你还愿意陪我练？ | 1.60秒 | 8.500秒 |
| scene-04 | 当然。明天，我也在。 | 2.40秒 | 12.333秒 |
| scene-05 | 好。那我们明天见。 | 2.56秒 | 16.417秒 |

先做第4镜完整4秒关键表演，检查后才扩展。第4镜v1含模型生成的无关英文样文字并略早开口，拒绝；移除提示词中的台词引号，增加第6/72帧闭口guide重做v2，实际查看96帧全画面/脸部并1倍速播放后采用。

第2镜v1开口约早0.29秒，拒绝；加入第8/47帧闭口guide后v2第一段约第10帧开口，与活动帧10对应，第二段约提前2帧准备。第3镜v1在低分辨率阶段主动中止，加入第11帧闭口guide改做v2，其开口约第12帧对应语音第13帧。问后出现期待，并在尾部害羞垂眼，这是实际表演解读，未写成全程仰视。

第5镜从第3镜采用片段第68帧提取闭口期待原画，imagegen只改表情生成微笑guide，第9/42帧约束静音、第80帧引导微笑。最终为全新连续A2V，不是冻结/循环参考帧；开口约第10—11帧和44帧，与两段语音对应，说完后闭口微笑、呼吸和眨眼。

钢琴为本片原创程序合成的稀疏五小节（Cmaj7/Am9/Fmaj7/Gsus/C6），配合低音量教室空气及远处鸟鸣；钢琴约-33dBFS RMS，合成音量0.85，环境约-52dBFS RMS。字幕为本地Noto Sans SC，许可`docs/NOTO-OFL.txt`，逐句按实际音轨起止安排。

- Remotion初始AAC有11ms尾部填充；本片导出脚本自动复制视频码流，仅修整AAC尾部并以320kbps编码，使音频/视频/容器均严格20.000秒。原始导出留在`outputs/intermediate`，没有改变对白语速或时点。

技术核对不能代替艺术判断。代理无法直接听辨音色和混音听感；没有把ASR、波形相关或时长当作逐音素口型评分。仍保留少量自然的预备口部动作，近景尾部略有向镜头内收的转头。用户试听、逐音素满意度与最终验收保持待确认，没有自动填写用户批准。
