# 风起山坡 · 三秒风格短测

日期：2026-11-12。风格：handpainted-film，手绘动画电影风。

目标：基于用户指定的宫崎骏动画电影视觉方向，制作原创乡间场景，检验画风在真实连续运动中是否稳定；没有使用既有电影画面、角色或原声。

- 规格：16:9，1280×720，24fps，72帧，3秒。
- 人物：栗棕短发少女，米白衬衣、砖红裙，站在乡间山坡，嘴部可见。
- 单镜动作：微抬头感受风、轻眨眼、收为淡淡闭口微笑，头发/衣角/草木随风轻动。
- 镜头：固定中景，人物右侧，左侧保留田野与远山空间；暖色下午光。
- 美术：手绘线稿人物、水粉/水彩背景、笔触和自然景深；完整方向见docs/style.json。
- 声音：无对白，无字幕，无配乐；本片原创程序合成风/草木声。
- 后端：内置imagegen原画；独立LTX-2.3 q4/MLX连续I2V；Remotion合成。
- 检查：逐帧人物与环境，1倍速连续播放，随后技术检查；用户艺术验收保持待确认。
