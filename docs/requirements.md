# 漫声片场需求

记录日期：2026-11-11。当前项目：Anime Scene Forge。名称沿用原会话：**漫声片场 · Anime Scene Forge**，技能标识 `anime-scene-forge`。

## 目标与来源

将 video-creation 项目《灌篮高手》樱木与晴子会话中的制作、配音、口型返工经验，落为可持续开发和验证的通用 Agent Skill。原会话已经有 v0.1 源码；当前仓库从该源码迁入维护。当前用户明确指定所有新测试视频放 `examples/`，每个视频一个子目录。

## 特定历史案例与通用规则

樱木与晴子的历史案例是30秒、720帧、24fps，前期人物造型、湘北旧体育馆、经典国语风格 AI 角色声音。它们是该案例的偏好，不是今后每个视频的固定角色、时长、语言或风格。

需要保留的通用经验：说话者与倾听者明确；嘴部与眉眼、视线共同表演；驱动音频不含配乐、保留头尾静音；换声音/节奏须重做讲话镜头；重生成后按新接触帧重标拍手等音效。闭口 guide 可作为修复手段，不能照抄历史帧号。

## 当前交付边界（v0.4.1）

已完成项目初始化、会话复核、技能源码、独立工程初始化器、工程检查与分发机制，以及《明天，我也在》独立20秒真实制作。v0.3.0增加随包提示词示例，并回写预览和音频尾部修复。用独立技术样例验证新版导出链路；合成测试不当作动漫成片，测试视频与媒体不进入分发Skill。

2026-11-12新增style参数和两套可执行风格方案。风格与后端分别选择；默认classic-anime，handpainted-film用于绘画感背景与细微环境表演。原画、视频、声音、审看与导出来源均关联本片profile；旧工程不自动迁移。新样片的实际完成和检查情况以该片制作记录为准，不预先认定艺术通过。

同日按用户分发要求，将可复制提示词统一维护在examples/prompts，并仅将该目录的Markdown/TXT/JSON纳入Skill包。其他examples子目录仍为独立视频工程，不随Skill分发；两类目录有不同用途。海边花山滑板为提示词方案，未制作该影片。打包不代表新模型、新宿主或新动作已经验收。

MLX固定版本适配器已在本机独立影片中实际运行；Claude Code内完整生产、Windows/Linux、CUDA/云端、新机器和多人重叠对白仍需实测。代理不能直接试听，内部检查与用户艺术验收分别记录。无相关能力时交付已完成部分和明确缺项，不伪装成已支持。
