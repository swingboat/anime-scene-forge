# 《海风里的滑板》· 12秒完整制作请求

这是可复制的制作方案，尚未制作或验收。先用2–4秒验证滑行、重心和脚板接触；按实际结果调整动作或机位。

## 可复制请求

```text
使用 $anime-scene-forge 制作12秒二维动画短片《海风里的滑板》，style选择 handpainted-film。

【场景与气氛】
一座临海的山，山坡上开满白色、粉色和淡紫色的鲜花。一条平缓的柏油路沿山坡蜿蜒，花草随海风轻摇。远处是开阔的大海，阳光在海面闪烁，天空明净、云朵舒展。
一个小女孩自在地滑着滑板穿过这片风景。感觉轻盈、自由、宁静，像暑假里无忧无虑的下午。

【人物与动作】
只有一个小女孩，短发，穿米黄色上衣、蓝色短裤、白色运动鞋。全片保持同一张脸、发型、服装和同一块滑板。
她沿柏油路平稳滑行，膝盖微屈，身体保持重心，双臂轻轻调整平衡，偶尔望向大海，露出满足的微笑。头发和衣角随风轻动。
自然速度，脚与板面、车轮与路面的接触清楚，滑板数量和结构稳定。以已有速度的平稳滑行为主，不添加跳跃或复杂花式。

【镜头】
0–4秒：远景建立山、花海、大海和道路的空间关系，女孩滑入画面。
4–8秒：侧面跟拍，完整看见女孩与滑板，表现滑行、重心和平衡。
8–12秒：斜后方远景，她沿花海间的道路滑向前方，画面打开，让大海与天空占据更多空间，安静收尾。
保持滑行方向、光向和地理关系连续。

【美术与声音】
清楚而柔和的人物线稿、细腻水粉背景、自然午后光和丰富克制的色彩。花海、远山与大海有空间层次，运动中保持统一画风。
无对白、无字幕。轻柔海风、远处海浪和滑板轮子滚过柏油路的声音，保留开阔安静的空间感。

【制作与交付】
16:9，1280×720，24fps，288帧。在 examples/coastal-skateboard-12s/ 新建独立工程，目录已存在时换新名称。
先内部制作2–4秒完整可见女孩与滑板的滑行短测，检查重心、脚板接触、车轮贴地、人物身份及背景稳定后再扩展。
使用真实连续动画，按1倍速检查全部镜头；物体或人体核心错误应修正或重新生成。
交付MP4、独立可编辑工程、提示词、来源和实际检查记录。区分已制作、内部检查与用户验收。
```
