# 已有影片的对白口型修复

先把方括号中的工程目录换成实际目录，再复制请求。该示例用于已有工程；不初始化覆盖它，也不以新声线掩盖原片的口型问题。

## 可复制请求

```text
使用 $anime-scene-forge 修复这个已有Remotion工程的可见对白表演：
工程目录：[填写当前视频工程目录]

先阅读工程内的production.json、对白音频、生成记录、选片记录和已有检查说明。
保留现有台词、已采用的角色声线、正常语速、总时长和已正确的镜头。定位哪些讲话镜头存在提前开口、静音中持续说话、说完不闭口、表情不符或倾听者一起张嘴的问题。

从最明显的问题中选一个2—4秒片段先修：用最终采用的对白WAV补真实头尾静音，以该音轨驱动新的连续表演；配乐不进入driver。需要时，用同一人物和场景的干净闭口或收尾画面作guide，时点依据本次音轨确定。

保持角色脸型、发型、服装、光照、机位和视线一致。单人镜头只描述画外朋友的方向，避免生成额外人物。按1倍速检查开口前、停顿和收尾的嘴型、眼神与表情，再扩展到其余问题镜头。

不要通过移动最终声音、加速/减速、循环、冻结或裁掉核心人物来隐藏问题。保留原候选和失败记录，修复使用新take名称。实际需要改变声音时，先说明原因，并将相关画面一同重做。

交付新的修复版MP4、更新后的可编辑工程，以及逐镜头修复/检查记录。区分技术通过、内部视觉检查与用户验收；无法直接听辨的部分如实记录。
```
