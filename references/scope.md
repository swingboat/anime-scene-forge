# 适用范围

## 第一版定义

“少角色、短时长、表演驱动的二维动漫叙事短片”。典型内容是日常对话、鼓励、害羞、自信、赛前/赛后反应、轻量教学情境，以及站稳、转头、挥拳、收球等单一简单动作。可制作原创角色，也可按用户提供的角色与场景参考保持一致性；不把AI生成图称为官方原画。

| 情况 | 适配程度 | 处理 |
|---|---|---|
| 1–3名主要角色，日常互动、对白与情绪反应 | 优先适用 | 固定身份/场景，2–4秒连续表演，按音频驱动讲话镜头 |
| 无对白角色表演或画外旁白 | 适用 | 连续I2V；按实际叙事添加旁白、字幕或环境音，不强迫角色对嘴 |
| 简单体育动作、少量固定物体 | 有条件 | 先验证握持/重心/接触；必要时用程序合成固定物体 |
| 多人高速交叉、攻防、运球、扣篮、打斗、拥抱接触 | 需要额外验证 | 缩短动作、拆机位或使用专门动作/物理后端；本路线不保证一次成功 |
| 竖屏、60秒以上连续故事或大量角色 | 可扩展但未完整验证 | 重新做画幅、机位、资源预算和关键镜头测试 |
| 纯PPT轮播、商业信息图、动态图表、网页录屏 | 不应自动触发 | 使用相应图文/动态图形制作流程 |
| 真人换脸、精确复刻真实演员声音、长片制作 | 不属于第一版能力承诺 | 按用户目标另选工具和验证方法 |

10–60秒是任务选择建议，不是模型保证。已有经验只验证过20秒与30秒成片、约2–4秒源片段。本 Skill 没有绑定特定漫画、角色、运动项目、语言、配音版本或暖色球馆风格。

第一版模板每镜头保存一条采用对白和一名主要说话者，多角色轮流讲话按分镜拆段。多人重叠对话或复杂多轨调度需要扩展时间轴及后端适配，不能直接当作已有能力。

## 触发例子

- “做一段30秒的二维动漫短片，两个人在车站道别，有日语对白和中文字幕。”
- “让这位原创角色鼓励队友，保持参考原画风格，20秒。”
- “修复这段动画的配音、嘴型和表情不同步问题。”

“把销售数据做成动画图表”不应自动选择本 Skill。“做10分钟高强度篮球比赛”需要重新规划技术路线，不能直接套短对话流程后承诺相同质量。
