# 可替换生成后端的约定

Skill负责制作与检查流程，后端负责生成媒体。Agent使用宿主的实际工具、CLI或已授权服务；不要把某种工具名写成跨Agent必需接口。

| 能力 | 输入 | 返回/保存到当前视频 |
|---|---|---|
| image | 角色/场景参考、提示词、目标画幅 | 完整原画；供应方、提示词、输入/输出哈希、实际路径与许可来源记录 |
| tts | 角色配置、语言、文本、情绪 | 逐句WAV，实际采样率/时长；角色和模型/修订、参数、来源、哈希 |
| i2v | 原画、主要动作、机位、规格 | 连续原速视频，实际fps/帧数；输入图、seed、版本与提示词记录 |
| a2v | 与i2v相同，另有含头尾静音的对白 | 使用该音轨驱动的连续表演；登记驱动音频SHA256，不自行换词/重新合成声音 |

模板使用public内相对素材路径；生成记录在docs/generation，至少包括mode、backend、版本、input image/audio/prompt hash、规格、参数、输出候选、耗时和失败情况。含对嘴对白的镜头需记录generation，其audioSha256与采用driverFile一致。最终选择和裁切再由select命令登记，视觉检查独立保存。

模板读取的生成记录字段是`mode`（a2v/i2v）、`audioSha256`（a2v必需）、`output`（项目相对文件路径，含public前缀）和`outputSha256`。其余来源和参数也应保存。output指原始候选，不是重新编码后的选片；两者哈希各自记录。

采用镜头必须通过`select`登记`shot.selection`；draft/final检查原始候选、采用片段和选帧来源的路径/哈希。A2V记录的output必须就是选片源。讲话镜头的选片起点必须等于`dialogue.driverStartFrame`；默认0。需要从非零源帧选片时，先用`pad-voice --source-start N`建立相应驱动，再生成候选，最后`select --start N`，不能后移画面而保持声音时点不变。

若后端会自行重生成声音，不能直接声称它匹配既有配音。选择保持输入音轨的模式，或重新定义整套声画方案并核对成片。需要固定物体时允许生成表演与程序合成结合，但校准交接、遮挡和事件。

更换后端前先测一个2–4秒关键镜头：保真、手/脸稳定、正常速度、可见对白与情绪。记录其真实适用范围。CUDA官方推理或云服务可按此约定适配，但本包没有声明这些适配器已实现或已测试。
